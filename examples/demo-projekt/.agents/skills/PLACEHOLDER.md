# Projektspecifikke skills — Codex

Skills der kun giver mening i dette projekt, bor her: domæne-, kunde- og
værktøjsviden som resten af setuppet ikke skal bære rundt på.

Fælles arbejdsgange hører i mothershipet. Reglen: genbrugelig på tværs af
projekter er core; ellers bliver skillen lokal her.

Mappen er tom med vilje. Opret første skill, når projektet faktisk har en
gentagelig arbejdsgang — ikke på forhånd.
